Política de privacidad de Clippers Publicador

Última actualización: 23 de noviembre de 2026

Clippers Publicador es una aplicación de uso personal. Su única función es publicar videos en las páginas de Facebook que administra su propietario, a petición suya.

Datos que trata

La aplicación solo la usa su propietario. Para publicar, guarda el identificador de las páginas de Facebook que él mismo conecta y el permiso de acceso que Facebook concede para publicar en ellas. No recoge datos de visitantes, seguidores ni de ninguna otra persona.

Para qué se usan

Únicamente para publicar en esas páginas el contenido que el propietario decide publicar y para consultar el estado de esas publicaciones.

Con quién se comparten

Con nadie. Los datos no se venden, no se ceden a terceros y no se usan para publicidad ni para elaborar perfiles. Solo se intercambian con Facebook, como exige su API para publicar.

Dónde se guardan y por cuánto tiempo

En el equipo del propietario, mientras la página siga conectada. Al desconectar la página, o al retirar el acceso de la aplicación desde la configuración de Facebook, el permiso deja de ser válido y se elimina.

Eliminación de datos

Como la aplicación no guarda datos de otras personas, no hay nada que eliminar a petición de terceros. El propietario puede eliminar los suyos en cualquier momento desconectando la página en la aplicación o quitando «Clippers Publicador» en Facebook, en Configuración → Integraciones comerciales.
